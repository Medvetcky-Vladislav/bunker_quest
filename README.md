# 🏚️ Текстовый квест на выживание

Постапокалиптическая текстовая приключенческая игра на Python. Вам предстоит пережить ядерную войну, добраться до бункера и восстановить его, чтобы спастись от радиации.

## 📖 Описание игры

Началась ядерная война. Бомба запущена в вашу сторону. У вас есть лишь один шанс — успеть добраться до спасительного бункера.

По пути вам придётся:

- Принимать решения, от которых зависит жизнь вашей группы
- Встречать выживших (или не совсем)
- Сражаться с монстрами (а может, это и не монстры вовсе...)
- Восстанавливать бункер: вентиляцию, водопровод, электричество
- Управлять ограниченными запасами еды и воды

**Цель:** полностью восстановить бункер и пережить 5 лет, пока радиация не исчезнет.

## 🎮 Управление

Игра полностью текстовая. Вводите ответы с клавиатуры:

| Ответ | Действие |
|-------|----------|
| `да` / `нет` | Согласие или отказ |
| `длинная` / `короткая` | Выбор дороги |
| `бой` / `мир` | Тактика встречи с монстрами |
| `лифт` / `лестница` | Способ передвижения |
| `хранилище` / `генератор` / `вода` / `родник` / `теплица` / `зал` | Переход между комнатами |
| `открыть` / `не открыть` | Управление вентиляцией |

⚠️ **Внимание:** регистр и опечатки имеют значение — вводите ответы точно так, как указано в подсказках.

- основной файл игры
- `road.py` — модуль анимации дороги
